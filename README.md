# UVify ☀️

UVify is a compact app for tracking solar activity and general weather information in your city. It's location-independent, allowing you to view information anywhere in the world — for example, when planning a trip to a hot country.

## Features

- 🌍 **Location-independent** — search any city in the world
- 🌡️ **Weather info** — current conditions and forecasts for 3 days
- ☀️ **Solar activity tracking** — UV index and sun exposure data
- 🎨 **Skin tone options** — personalized sun exposure assessment
- 🌐 **Bilingual support** — English and Spanish
- 📏 **Adjustable units** — imperial and metric
